# 🤝 Contributing to Femto Physics & Proposing Video Topics

We welcome contributions, scientific corrections, and topic proposals from physicists, engineers, students, and enthusiasts worldwide!

---

## 💡 How to Propose a Video Topic
Have a complex physics phenomenon you want decoded with full differential equations and cinematic animations?

1. **Check Existing Issues**: Check the [GitHub Issues](https://github.com/TheFemtoPhysics/Femto-Physics/issues) tab to see if your topic is already proposed.
2. **Open a Topic Proposal Issue**: Use the template:
   - **Topic Title**: (e.g., *Xenon-135 Poisoning & The Chernobyl Reactor Pit*)
   - **Core Physics & Equations**: (e.g., Iodine-135 decay kinetics, absorption cross-section of 2.6 million barns)
   - **Visual Concept Ideas**: (e.g., Spatial flux tilt, 3D poison well representation)
   - **Key Literature / Data**: (e.g., IAEA Report, ENDF/B-VIII.0 cross-sections)

---

## 🛠️ Contributing Code or Mathematical Notes
1. **Fork the Repository**: Create your own fork of `github.com/TheFemtoPhysics/Femto-Physics`.
2. **Create a Feature Branch**: `git checkout -b topic/xenon-poisoning-notes`.
3. **Submit a Pull Request**: Detail your derivation, code snippets, or documentation corrections.

### Code Style Standards:
- Python code should use NumPy, SciPy, or Matplotlib.
- Equations should be formatted in standard LaTeX MathJax.
- Visuals should adhere to the channel's dark slate palette (`#0a0e17` obsidian background with `#00e5ff` cyan and `#ffd54f` amber accents).
